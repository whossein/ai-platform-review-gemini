About the Project

The AI Code Review Platform is a powerful, multi-agent automated code review system. It acts as an intelligent pair programmer, seamlessly integrating with your git workflow (GitLab, local diffs, etc.) to analyze code changes, detect bugs, and suggest improvements.

Key Features:

  • Multi-Provider Support: Works with OpenAI, Anthropic, Gemini, OpenRouter, Avalai, and Ollama (Local AI).
  • Agentic Workflow: Employs multiple specialized AI agents (Security, Performance, Best Practices) to provide a comprehensive review.
  • Auto-Publishing: Automatically posts review comments directly to your GitLab Merge Requests.
  • Budget Control: Set hard limits on API usage costs to prevent unexpected bills.
  • Provider Toggling: Easily enable, disable, or switch default AI providers with fallback mechanisms.

درباره پروژه

پلتفرم بررسی هوشمند کد (AI Code Review) یک سیستم خودکار و چندعامله (Multi-Agent) است که مانند یک برنامه‌نویس ارشد در کنار شما قرار می‌گیرد. این پلتفرم با تحلیل کدهای جدید (از طریق GitLab یا فایل‌های Local)، باگ‌ها را شناسایی کرده و راهکارهای بهینه‌سازی پیشنهاد می‌دهد.

ویژگی‌های کلیدی:

  • پشتیبانی از هوش مصنوعی‌های متنوع: اتصال به OpenAI، Anthropic، Gemini، OpenRouter، سیستم ایرانی Avalai و حتی Ollama برای پردازش آفلاین.
  • ارزیابی چندجانبه: استفاده از چندین نماینده هوش مصنوعی برای بررسی همزمان امنیت، پرفورمنس و معماری تمیزِ کد.
  • ثبت خودکار نظرات: توانایی ارسال مستقیم کامنت‌های اصلاحی بر روی Merge Request های گیت‌لب.
  • مدیریت هزینه‌ها: امکان تعیین سقف بودجه برای مصرف API تا از هزینه‌های ناخواسته جلوگیری شود.
  • مدیریت منعطف سرویس‌دهنده‌ها: خاموش و روشن کردن سریع هوش‌مصنوعی‌های مختلف و سوییچ خودکار در صورت قطعی هر کدام.
